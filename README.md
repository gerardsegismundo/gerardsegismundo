# Cloud / DevSecOps Engineer

Building secure, scalable cloud platforms and automation systems on AWS with a focus on reliability, security, and developer productivity.

---

## 🧭 Summary

Cloud and DevSecOps engineer focused on designing and operating production-grade infrastructure. Experienced in infrastructure as code, CI/CD automation, containerized workloads, and security-first cloud architectures.

Strong emphasis on building repeatable systems that scale across environments and teams.

## 🧰 Core Expertise

### Cloud & Infrastructure

* AWS Cloud Architecture (multi-account, multi-AZ design)
* Infrastructure as Code (Terraform, modular patterns)
* Networked cloud systems (VPC design, IAM architecture)

### Platform Engineering

* CI/CD pipelines (GitHub Actions, CodePipeline)
* GitOps workflows and automation strategies
* Developer platform enablement and workflow optimization

### Security Engineering (DevSecOps)

* IAM design and least-privilege access models
* Policy-as-code enforcement
* Vulnerability scanning (Trivy, Checkov)
* Secure pipeline design and hardening

### Containers & Orchestration

* Dockerized workloads
* Kubernetes fundamentals and deployment patterns
* Cloud-native application delivery

## 🏗️ Featured Work

* Built reusable pipeline patterns for scalable delivery

* Modular Terraform architecture for AWS environments

* Automation over manual processes
* Repeatability and consistency across environments
* Systems designed for scale and failure tolerance
